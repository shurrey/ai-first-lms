# T-D-001 — Postgres container + connection helper

**Workstream:** data-mcp
**Size:** M
**Status:** open
**Dependencies:** none

## Context
The data layer needs a Postgres 16 + pgvector database and a reusable async connection helper.
All MCP servers, the seed script, and graph_lib use this connection helper.

## Acceptance criteria
- [ ] `src/data-mcp/db.py` provides `get_pool()` returning an asyncpg connection pool.
- [ ] Pool reads `DATABASE_URL` from env (with a sensible default for local dev).
- [ ] `pyproject.toml` declares dependencies: asyncpg, pydantic, pydantic-settings, alembic, sqlalchemy.
- [ ] `alembic.ini` and `alembic/env.py` are configured and runnable.
- [ ] Unit test verifying the pool can be created (mocked or testcontainers).
