## Acceptance criteria
Copied from spec.md; the source section is in parentheses after each item.
- [ ] `current_user()` reads the cookie, looks up `sha256(token)`, rejects revoked or expired sessions, applies sliding expiry (bumps `last_seen_at` at most once a minute) and returns an `AuthContext(person_id, roles, active_role, enrollments, advisee_ids)` cached per request (§4.4).
- [ ] CSRF: every non-GET `/api/*` request except `/api/auth/login` must send `X-CSRF-Token` equal to the session's `csrf_token`; missing or mismatched returns `403` (§4.4).
- [ ] CORS keeps explicit origins `http://localhost:3000` and `http://localhost:3100` with `allow_credentials=True`; never `*` (§4.4).
- [ ] Login works over plain `http://localhost` with `COOKIE_SECURE=false` (§4.8).
