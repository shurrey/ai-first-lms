## Goal

## Acceptance criteria
Copied from spec.md; the source section is in parentheses after each item.
- [ ] `/login` route: labelled username and password fields, show-password toggle, submit button, `role="alert"` error region; on success redirect to `/me.home_route`; WCAG 2.2 AA incl. 3.3.8 Accessible Authentication (paste and password managers allowed) (§4.6.1).
- [ ] `middleware.ts` redirects to `/login` without `lms_session`; client calls `/api/auth/me` on load; any `401` clears state and redirects to `/login?next=…` (§4.6.2).
- [ ] All `fetch` calls use `credentials: "include"` and send `X-CSRF-Token` from `lms_csrf` on non-GET; `EventSource` uses `{ withCredentials: true }` (§4.6.3).
- [ ] `components/ContextPane/PersonaSwitcher.tsx` deleted; `persona`/`setPersona` removed from `lib/session-context.tsx`; persona comes from `/me` (§4.6.4).
- [ ] Course selector built from `/me.enrollments`; advisor/admin get an "All my students" / "Institution" scope entry (§4.6.7).
- [ ] No UI path lets a user choose to act as a different person (§4.8).
- [ ] axe-core scan of `/login`: 0 serious or critical violations (§4.8).
