**Workstream:** data-mcp
**Size:** M
**Status:** open
**Dependencies:** T-D-002, T-D-004

## Context
Generate and store embeddings for all node descriptions/titles to enable semantic search.

## Acceptance criteria
- [ ] Embedding generation using a local model or Anthropic embeddings API.
- [ ] Embeddings stored in the nodes.embedding column (vector(1536) or similar).
- [ ] Pipeline runs on seed and on content creation.
- [ ] ivfflat index enables fast approximate nearest-neighbor search.
- [ ] Unit test: embed a query, find nearest nodes, verify relevance.
