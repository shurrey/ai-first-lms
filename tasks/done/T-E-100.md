**Workstream:** engine

**Size:** M
**Status:** done
**Spec:** spec.md §0.2a, §3A S3
**Dependencies:** None (container verification needs T-P-099)

## Goal
Turn outbound certificate verification back on by building every HTTPS client through a truststore-backed helper.

## Context
- The 8 `verify=False` sites exist because certifi lacks the corporate TLS-inspection root; truststore uses the OS store, which has it.
- Sites: `engine/agents/runner.py:345`, `engine/graph/interpret.py:84`, `engine/brief.py:577`, `engine/analyst.py:105`, `engine/podcast.py:64,138`, `engine/api/podcast.py:63`, `data_mcp/seed/generate_skills.py:124`.

## Acceptance criteria
Copied from spec.md; the source section is in parentheses after each item.
