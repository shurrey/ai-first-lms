# T-A-001 — Agent base class / Claude Agent SDK scaffold

**Workstream:** agents
**Size:** L
**Status:** open
**Dependencies:** none

## Context
Every sub-agent needs a common foundation: a base `run()` function signature, PersonaContext and ToolBag types, structured output helpers, and the prompt-injection guard pattern. This task creates that scaffold so all ten agents can build on it.

## Acceptance criteria
- [ ] `src/agents/__init__.py` exports `BaseAgent`, `PersonaContext`, `ToolBag`, `AgentResult`.
- [ ] `BaseAgent` is an abstract class with `async def run(inputs: dict, persona: PersonaContext, tools: ToolBag) -> dict`.
- [ ] `PersonaContext` is a Pydantic model with `person_id`, `roles`, `display_name`, `course_id`.
- [ ] `ToolBag` wraps MCP tool calls and logs every invocation.
- [ ] `AgentResult` is a Pydantic model matching the output envelope agents return.
- [ ] `<user_content>` wrapping utility exists for prompt-injection defense.
- [ ] Unit tests pass: `python -m pytest src/agents/tests/ -q`.

## Files touched
- `src/agents/__init__.py` (new)

## Notes
- Use Pydantic v2 for all models.
- ToolBag should be async and log tool name + args + latency.
- Do not implement any specific agent yet — just the scaffold.
