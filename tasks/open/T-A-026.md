## Context

## Acceptance criteria
- [ ] Given course goals + target outcomes, generates a module sequence.

- [ ] Aligns to external standards (e.g., ABET, Common Core) via standards.lookup.
- [ ] Generates a syllabus document saved as draft.
- [ ] Checks outcome coverage: every stated goal has at least one aligned module.
- [ ] 5+ eval cases (intro course, advanced course, interdisciplinary).
