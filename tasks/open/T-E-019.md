# T-E-019 — Structured logging (every event, agent call, tool call)

**Workstream:** engine
**Size:** M
**Status:** open
**Dependencies:** T-E-005, T-E-010

## Context
Every orchestrator action should be logged in structured JSON for debugging and observability.

## Acceptance criteria
- [ ] All events emitted are logged with full payload.
- [ ] Agent invocations logged with: agent_name, input_summary, duration_ms, token_count.
- [ ] Tool calls logged with: tool_name, input, output_summary, duration_ms.
- [ ] Log level configurable via LOG_LEVEL env var.
- [ ] Logs go to stdout in JSON format (for Docker/compose collection).
