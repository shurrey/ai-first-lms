## Acceptance criteria

- [ ] `subgraph(root_ids, max_depth)` — extract a connected subgraph.
- [ ] `path_to_mastery(person_id, target_node_id)` — prerequisite chain with mastery levels.
- [ ] `evidence_summary(person_id, node_ids)` — aggregate evidence per node.
- [ ] `aggregate(scope, metric, window)` — compute aggregate metrics.
- [ ] All functions are async and use the shared connection pool.
- [ ] Unit tests with seeded graph data for each function.
