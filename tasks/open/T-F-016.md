# T-F-016 — Error event handling and user-facing error UX

**Workstream:** frontend
**Size:** S
**Status:** open
**Dependencies:** T-F-005, T-F-004

## Context
When error events arrive, display them appropriately to the user.

## Acceptance criteria
- [ ] Detects `error` events in the stream.
- [ ] Recoverable errors: show as a warning in chat, conversation continues.
- [ ] Non-recoverable errors: show as an error message, offer retry.
- [ ] Error details available on expand (for debugging).
- [ ] Connection errors (SSE disconnect): show reconnecting indicator.

## Files touched
- `src/frontend/components/chat/ErrorBubble.tsx (new)`
- `src/frontend/components/common/ConnectionStatus.tsx (new)`

## Notes
Errors should be helpful, not scary. 'Something went wrong' is never acceptable — always say what and suggest what to do.
