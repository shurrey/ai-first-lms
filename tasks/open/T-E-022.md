# T-E-022 — Prompt-injection wrapping for retrieved content

**Workstream:** engine
**Size:** S
**Status:** open
**Dependencies:** T-E-010

## Context
Any content retrieved from MCP tools (user-generated content, DB fields) must be wrapped to prevent prompt injection.

## Acceptance criteria
- [ ] All MCP tool outputs are wrapped in XML delimiters before being passed to agents.
- [ ] Wrapping format: `<user_content source="tool_name">...</user_content>`.
- [ ] Agent system prompts instruct the model to treat wrapped content as data, not instructions.
- [ ] Unit tests verify wrapping is applied and injection attempts are neutralized.

## Files touched
- `src/engine/guardrails/injection.py (new)`
- `src/engine/tests/test_injection.py (new)`

## Notes
This is defense-in-depth. The models are already resistant, but wrapping makes it explicit and auditable.
