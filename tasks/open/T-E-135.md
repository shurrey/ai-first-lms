# T-E-135 — Practice attempt checks don't inflate private evidence

**Workstream:** engine
**Phase:** 2 (spec.md §19.1)
**Size:** S
**Status:** open
**Spec:** spec.md §7.3, §12.5

## Goal
Re-checking the same practice item doesn't write a new attempt each click; attempts are recorded once per submission of a set.

## Acceptance criteria
- [ ] A repeated check of one item updates or dedupes rather than adding evidence rows.
- [ ] UI fakes match the PracticeAttempt contract (results[].expected is a string).
