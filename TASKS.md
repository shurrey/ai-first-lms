# TASKS.md

The master task catalog. Actual task files live in `tasks/open/<id>.md`. This file is the index — regenerated from the filesystem by CI and checked in. Do not edit this file directly; edit task files.

---

## Conventions

- Task IDs: `T-<workstream-prefix>-<number>`. Prefixes: `E` (engine), `A` (agents), `D` (data-mcp), `F` (frontend), `P` (platform), `C` (contract-change), `I` (integration).
- Each task file has: **Acceptance criteria**, **Files touched**, **Dependencies**, **Notes**.
- Size: each task should be completable in one claim session (1-4 hours of agent work).
- If a task grows beyond that, split it before claiming.

## Task file template

```markdown
# T-E-003 — Orchestrator: SSE streaming helper

**Workstream:** engine
**Size:** M
**Dependencies:** T-E-001, T-E-002

## Acceptance criteria
- [ ] Given an async generator of events, produces an SSE stream conforming to contracts/events.md.
- [ ] Handles client disconnect cleanly.
- [ ] Unit tests cover the happy path and a disconnect case.
- [ ] Passes `uv run pytest src/engine/tests/test_streaming.py`.

## Files touched
- `src/engine/streaming/sse.py` (new)
- `src/engine/tests/test_streaming.py` (new)

## Notes
Use sse-starlette as the base. Do not invent a format; follow contracts/events.md exactly.
```

## Task file: one real example

Here's what `tasks/open/T-E-003.md` actually looks like on disk. Use this format for every task file.

```markdown
# T-E-003 — Orchestrator: SSE streaming helper

**Workstream:** engine
**Size:** M
**Status:** open
**Dependencies:** T-E-001

## Context
The orchestrator needs to stream events to the frontend per contracts/events.md.
Every event has the envelope { event, session_id, turn_id, sequence, timestamp, payload }.
The helper is reused by /api/stream and by tests.

## Acceptance criteria
- [ ] `stream_events(event_source: AsyncIterator[Event]) -> StreamingResponse` works.
- [ ] Envelopes conform exactly to contracts/events.md.
- [ ] Client disconnect does not leak the async generator.
- [ ] `sequence` is monotonic per (session_id, turn_id).
- [ ] Unit tests pass: `uv run pytest src/engine/tests/test_streaming.py -q`.

## Files touched
- `src/engine/streaming/__init__.py` (new)
- `src/engine/streaming/sse.py` (new)
- `src/engine/streaming/events.py` (new; Pydantic models for each event)
- `src/engine/tests/test_streaming.py` (new)

## Notes
- Use `sse-starlette` as the base.
- Do not re-invent the event schema; treat contracts/events.md as law.
- If the schema needs a change, stop and open a T-C task.

## On completion
- Commit: `feat(engine): T-E-003 — SSE streaming helper`
- Move task file: `git mv tasks/claimed/engine/T-E-003.md tasks/done/T-E-003.md`
```

Task-authoring discipline is what makes the ralph-wiggum loop work. Sloppy tasks produce sloppy code.
